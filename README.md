# Estudos de Engenharia de Software

Repositório de exercícios e trabalhos da graduação de Mateus Henrique de Souza na Descomplica UniAmérica. É um histórico de aprendizagem, organizado por semestre; não é uma aplicação única.

## Organização

| Pasta | Conteúdo |
|---|---|
| [1-semestre](1-semestre/) | Sistema de mercado em C, dividido em versões evolutivas. |
| [2-semestre](2-semestre/) | Exercícios JavaScript e trabalhos acadêmicos. |
| [3-semestre](3-semestre/) | Exercícios Java, orientação a objetos, Swing e sistemas de estudo. |
| [4-semestre](4-semestre/) | Spring Boot, Angular e testes automatizados. |

## Como estudar e executar

Escolha um exercício e leia o código e o README da pasta, quando disponível. Os requisitos variam: C exige compilador; Java pode utilizar Maven; projetos Angular têm seu próprio package.json. Não há um comando único que execute todo o repositório.

Exemplos com documentação própria:

- [Sistema de mercado em C](1-semestre/README.md).
- [API calculadora e testes](4-semestre/testes/teste-master/README.md).
- [API de estatísticas](4-semestre/spring-boot/AULA-TESTE-INTEGRACAO/estatisticas/README.md).

## Contexto e limites

Os exercícios representam diferentes momentos do curso e podem estar incompletos. Materiais de aula, códigos de referência e trabalhos coletivos preservam a autoria original. Não são apresentados como sistemas prontos para produção.
