# 🛒 Sistema de Mercado em C

Este projeto é um sistema de mercado desenvolvido em linguagem C, com interface via terminal.  
Foi construído em **4 partes evolutivas**, cada uma adicionando novas funcionalidades e melhorias ao sistema original.

## 📌 Funcionalidades

- Cadastro de produtos
- Visualização do estoque
- Registro de vendas
- Cálculo de totais
- Uso de arquivos `.txt` para salvar os dados
- Interface por menus no terminal

## 🧠 Tecnologias utilizadas

- Linguagem C
- Interface via terminal
- Manipulação de arquivos `.txt`
